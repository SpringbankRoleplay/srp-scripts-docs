# SRP Scripts

Resources for FiveM servers. Every script page here covers installation, the
config options you can change, and the exports and events you can call.

<Callout type="info">
  New here? Start with [srp-core](/srp-core) — every other resource depends on it.
</Callout>

## Getting started

<Steps>
  <Step title="Get the resource">
    Paid resources are delivered through [our store](https://srp-scripts.com).
    After checkout the file sits in your Tebex account under Downloads.
  </Step>

  <Step title="Drop the files on your server">
    Extract the archive into `resources/[srp]/`. Keep the folder name as it
    ships — it's used in exports and event names.
  </Step>

  <Step title="Add it to server.cfg">
    Order matters: your framework, inventory, phone and notify resources first,
    then `srp-core` (so it can detect them), then our scripts.

    ```cfg
    ensure ox_lib
    ensure ox_inventory     # or your inventory / phone / notify resources
    ensure srp-core
    ensure srp-yourscript
    ```
  </Step>

  <Step title="Import the database">
    Run the included `.sql` file against your database. Skip this if the
    resource ships without a `sql` folder.
  </Step>

  <Step title="Restart and check the console">
    Start the server and watch the output. No errors during the resource's
    startup means you're done.
  </Step>
</Steps>

- the resource name and version
- your framework and inventory
- the error from your server or client console
