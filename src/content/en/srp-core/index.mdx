# srp-core

<ResourceHeader
  version="1.2.0"
  price="Free"
  status="stable"
  downloadUrl="https://github.com/SpringbankRoleplay/srp-core/releases/latest"
  githubUrl="https://github.com/SpringbankRoleplay/srp-core"
>
  Detects your framework and inventory on startup, then exposes one consistent
  API to every other SRP resource. Install it once and forget about it.
</ResourceHeader>

<Compatibility
  frameworks={[{ name: 'ESX' }, { name: 'Standalone' }]}
  inventories={[{ name: 'ox_inventory' }]}
/>

## Installation

<Steps>
  <Step title="Download the resource">
    Grab the latest release from GitHub and extract it into `resources/[srp]/`.
  </Step>

  <Step title="Add it to server.cfg">
    srp-core has to start before any resource that depends on it.

    ```cfg
    ensure ox_lib
    ensure srp-core
    ```
  </Step>

  <Step title="Restart">
    Check the console on startup — srp-core prints which framework and
    inventory it detected.
  </Step>
</Steps>

## Configuration

Options live in `config.lua`.

<Properties>
  <Property name="Config.Framework" type="string" defaultValue="'auto'">
    Force a specific framework instead of auto-detecting. Accepts `esx`,
    `standalone` or `auto`.
  </Property>

  <Property name="Config.Inventory" type="string" defaultValue="'auto'">
    Same idea for the inventory. Accepts `ox_inventory` or `auto`.
  </Property>

  <Property name="Config.Debug" type="boolean" defaultValue="false">
    Prints detection results and every bridge call to the console. Leave this
    off in production — it's noisy.
  </Property>
</Properties>

## Events

<Reference name="srp-core:playerLoaded" side="server" kind="event">

  this before reading anything about the player.
